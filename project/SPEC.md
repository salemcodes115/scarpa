Project Spec — Todo App

Goal: Build a small, accessible todo app that runs entirely in the browser.

Requirements
- UI to add, edit, delete tasks
- Mark items complete/incomplete
- Filter tasks by All/Active/Completed
- Persist tasks in `localStorage`
- Responsive layout for desktop and mobile
- No frameworks; plain HTML/CSS/JS

Acceptance Criteria
- Opening `index.html` shows the app
- Tasks persist across reloads
- Buttons and keyboard actions work (Enter to add, Esc to cancel edit)

Optional stretch
- Drag-and-drop reordering
- Export/import JSON
- Theme toggle
